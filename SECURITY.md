# Security policy

Report suspected vulnerabilities privately to **islishude@gmail.com**. Include
the affected commit/version, impact, and a minimal reproduction using synthetic
data. Do not include production credentials, private keys, or user data. Please
avoid public issues for undisclosed vulnerabilities; coordinate disclosure with
the maintainer over email.

Security maintenance targets the latest released version, or the current main
branch before the first release. Older pre-v1 versions have no guaranteed
backports. No response-time commitment is made. See [release policy](docs/release.md)
and the [security model](docs/security-model.md).
